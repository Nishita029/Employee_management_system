## Employee Salary Management System

The Employee Salary Management System is a menu-driven console application developed using C++.  
It allows efficient management of employee records including salary calculation, searching, updating, deleting, and generating salary slips.  
All employee data is stored persistently using file handling.

This project demonstrates core C++ concepts such as:
- Structures  
- File handling  
- Functions  
- Conditional logic  
- Temporary file replacement technique
